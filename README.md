# 지역 상권 혼잡도 분석 프로젝트

> 각 업종별 점포 수, 인구 수, 성비 등의 지역 데이터를 바탕으로 혼잡도를 분석하는 모델 생성

---

## 프로젝트 개요

- **목표**: 지역별 혼잡도 점수를 계산하여, 사용자에게 혼잡한 상권과 덜 혼잡한 상권을 비교 분석할 수있도록 제공
- **분석 대상**: 행정동 단위 지역
- **분석 요소**:
  - 각 업종별 점포 수
  - 인구 수
  - 남녀 인구 비율
  - 지역 면적
  - 
---

### 혼잡도 지수 공식

혼잡도 점수 = 100 × (
w₁ × 점포 밀도 비율 +
w₂ × 인구 밀도 비율 +
w₃ × 성비 편차 비율
)


### 항목별 계산 방식

- **점포 밀도** = 점포 수 ÷ 지역 면적 (km²)  
- **점포 밀도 비율** = 점포 밀도 ÷ 전체 지역 중 최대 점포 밀도

- **인구 밀도** = 인구 수 ÷ 지역 면적 (km²)  
- **인구 밀도 비율** = 인구 밀도 ÷ 전체 지역 중 최대 인구 밀도

- **성비 편차** = |남성 인구 - 여성 인구| ÷ 총 인구  
- **성비 편차 비율** = 성비 편차 ÷ 0.5 *(0.5는 최대 성비 편차 기준)*

---

### 성비 방향 정보

- 남성 인구 > 여성 인구 → `남초 지역`  
- 여성 인구 > 남성 인구 → `여초 지역`  
- 같음 → `성비 균형`

→ 혼잡도 점수 옆에 성비 방향도 함께 표기

---

### 가중치 예시

- w₁ = 0.5 (점포 밀도 영향)  
- w₂ = 0.3 (인구 밀도 영향)  
- w₃ = 0.2 (성비 편차 영향)  
- 조건: w₁ + w₂ + w₃ = 1.0

---

### 혼잡도 결과 예시

| 지역 | 혼잡도 점수 | 성비 방향 |
|------|--------------|-------------|
| 강남구 | 93.2 | 남초 지역 |
| 마포구 | 78.5 | 성비 균형 |
| 송파구 | 85.1 | 여초 지역 |

> 점수가 높을수록 상권이 더 붐비며,  
> 점포 수와 인구가 밀집해 있고 성비 불균형이 심할수록 혼잡도가 높게 나옴.

---

## 혼잡도 계산 방식 요약

1. API를 통해 지역별 상권 및 인구 데이터를 수집
2. 면적 기반으로 밀도 계산 후, **전체 데이터에서 최대값 기준으로 비율화**
3. 정규화된 비율에 가중치를 곱해 혼잡도 점수 산출 (0~100점)
4. 혼잡도와 성비 방향 결과를 DB에 저장 및 시각화

## 🗃 데이터베이스 테이블 설계

### `region` (지역 정보)

| 필드명 | 타입 | 설명 |
|--------|------|------|
| region_id | INT | 지역 고유 ID (PK) |
| name | VARCHAR | 행정동/구 이름 |
| area_km2 | FLOAT | 지역 면적 (제곱킬로미터) |
| lat | FLOAT | 중심 위도 |
| lng | FLOAT | 중심 경도 |

---

### `population_stats` (인구 통계)

| 필드명 | 타입 | 설명 |
|--------|------|------|
| id | INT | PK |
| region_id | INT | FK → region |
| date | DATE | 기준 일자 |
| total | INT | 전체 인구 수 |
| male | INT | 남성 인구 수 |
| female | INT | 여성 인구 수 |

---

### `restaurant_stats` (업종별 점포 수)

| 필드명 | 타입 | 설명 |
|--------|------|------|
| id | INT | PK |
| region_id | INT | FK → region |
| business_type | VARCHAR | 업종 구분 (예: 한식, 중식, 카페 등) |
| count | INT | 해당 업종 점포 수 |
| date | DATE | 기준 일자 |

---

### `congestion_score` (혼잡도 분석 결과)

| 필드명 | 타입 | 설명 |
|--------|------|------|
| id | INT | PK |
| region_id | INT | FK → region |
| score | FLOAT | 계산된 혼잡도 점수 (0~100점) |
| gender_bias | VARCHAR | 남초 / 여초 / 성비 균형 |
| date | DATE | 분석 기준 일자 |
| details_json | TEXT | 점포 밀도, 인구 밀도, 성비 편차 등의 비율 정보 JSON 저장
